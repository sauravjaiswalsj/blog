## 8 Step Framework - during technical interview

1. RESTATE     → "So we need to find X given constraints Y..."
2. EXAMPLES    → Walk through 1 small example by hand
3. BRUTE FORCE → "Naively I'd do... which is O(n²)"
4. OPTIMISE    → "The bottleneck is... can I use a [hash/heap/window]?"
5. PATTERN ID  → "This looks like [pattern] because..."
6. CODE        → Clean, modular, named variables
7. TEST        → Edge cases: empty input, single element, duplicates
8. COMPLEXITY  → State time + space, explain why
